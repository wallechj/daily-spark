# ✦ Daily Spark · 每日灵感小站

一个超轻量的静态小网站：每天打开，收获一句灵感。

## 功能

- **今日灵感**：每天自动轮换一句中英双语，点「换一句」手动翻看
- **🍅 专注番茄钟**：25 分钟倒计时，完成自动计数（存在浏览器本地）
- **🌟 今日小确幸**：随手记下开心的小事，刷新不丢失
- **🌙 深浅色主题**：一键切换，记住你的偏好
- **📊 灵感足迹**：统计看过的灵感、完成的番茄、记录的小确幸

## 本地预览

直接用浏览器打开 `index.html`，或：

```bash
npx serve .
# 或
python3 -m http.server 8000
```
